# Промпт для агента: сигнальная стратегия RSI 6H Mean-Reversion

Скопируй блок ниже целиком и передай другому агенту как ТЗ на внедрение в целевую торговую систему.

---

## ЗАДАЧА

Внедри в существующую торговую систему **отдельный сигнальный модуль / настройку** под названием:

**`RSI 6H Mean-Reversion Signals`**

Модуль:
1. Считает сигналы входа/выхода по фиксированным правилам.
2. Показывает на графике (любой ТФ) зоны **LOW / HIGH / ENTRY**.
3. Отдельно считает и показывает **6H-тренд** (UP / DOWN / NEUTRAL).
4. Позволяет опционально использовать 6H-тренд в торговых решениях через галочки.

Не сканируй весь рынок. Работай **только по белому списку символов**, который пользователь настраивает.

## БАЗОВЫЕ ИНДИКАТОРЫ

Все расчёты сигналов входа/выхода — на **основном таймфрейме стратегии = `6h`**.

| Параметр | Значение | Описание |
|----------|----------|----------|
| Timeframe | `6h` | Основной ТФ сигналов |
| RSI period | `14` | Классический RSI по close |
| EMA fast | `50` | Для тренда |
| EMA slow | `200` | Для тренда |
| Trend confirm bars | `3` | Сколько закрытий подряд относительно EMA200 |

На графике пользователь может смотреть **любой ТФ** (1m…1d). Сигналы модуля всё равно якорятся к 6H-логике, но визуально проецируются на текущий график (вертикальные маркеры / зоны / метки на соответствующих 6H-свечах).

## 1) RSI-СИГНАЛЫ (ядро стратегии)

### Вход (ENTRY)

| Условие | Сигнал | Смысл |
|---------|--------|-------|
| `RSI(14, 6h) ≤ 29` | `ENTER_LONG` | зона LOW / перепроданность |
| `RSI(14, 6h) ≥ 71` | `ENTER_SHORT` | зона HIGH / перекупленность |
| `30 ≤ RSI ≤ 70` | `WAIT` | нейтральная зона, входа нет |

Сигнал определяется **только RSI**. Тренд сам по себе вход не создаёт.

### Выход (EXIT) по RSI

Учитывается, был ли вход **по тренду** или **против тренда** (см. раздел 3):

| Позиция | Тип входа | Выход |
|---------|-----------|-------|
| LONG | по тренду (entry_trend = UP) | `RSI ≥ 65` |
| LONG | против тренда (entry_trend = DOWN/NEUTRAL) | `RSI ≥ 60` |
| SHORT | по тренду (entry_trend = DOWN) | `RSI ≤ 35` |
| SHORT | против тренда (entry_trend = UP/NEUTRAL) | `RSI ≤ 40` |

Если режим тренда выключен (см. галочки) — используй **пороги «по тренду»** как дефолт: LONG exit 65, SHORT exit 35.

### Зоны для UI (на любом ТФ)

Показывать на графике/панели:

| Зона | Условие (по 6H RSI) | Подпись |
|------|---------------------|---------|
| `LOW` | RSI ≤ 29 | «6H LOW — зона лонга» |
| `HIGH` | RSI ≥ 71 | «6H HIGH — зона шорта» |
| `EXIT_LONG_ZONE` | RSI ≥ 60 | «зона выхода лонга» |
| `EXIT_SHORT_ZONE` | RSI ≤ 40 | «зона выхода шорта» |
| `NEUTRAL` | иначе | «ожидание» |

Дополнительно на текущей 6H-свече (и её проекции на младший ТФ):
- бейдж `6H LOW` / `6H HIGH` / `6H WAIT`
- значение RSI 6H
- тренд 6H: `UP` / `DOWN` / `NEUTRAL`

## 2) ТРЕНД 6H (отдельный слой)

Тренд считается **только на 6H**, по EMA:

### UP
Минимум 2 из критериев (или жёстче — как в конфиге ниже), предпочтительно:
1. `close > EMA200`
2. `EMA50 > EMA200`
3. наклон EMA200 > 0 (EMA200 сейчас > EMA200 N баров назад)
4. минимум `3` последних close подряд > EMA200

### DOWN
Зеркально:
1. `close < EMA200`
2. `EMA50 < EMA200`
3. наклон EMA200 < 0
4. минимум `3` последних close подряд < EMA200

### NEUTRAL
Если условия UP/DOWN не выполнены.

Рекомендуемые флаги расчёта тренда:
- `require_price = true` (цена vs EMA200 обязательна)
- `require_candles = true` (N закрытий подряд)
- `require_slope = false` (наклон опционален)
- `min_confirmations = 2` из доступных критериев

Тренд **не заменяет** RSI-сигнал. Он:
- показывается всегда как контекст;
- опционально влияет на торговлю только если включены галочки ниже.

## 3) РЕЖИМЫ ИСПОЛЬЗОВАНИЯ ТРЕНДА (галочки UI)

В настройках модуля сделай три независимых/взаимоисключающих режима (или радиогруппа + чекбоксы):

### A) `use_trend = OFF` (по умолчанию можно OFF или ON — на усмотрение UI)
- Сигналы входа/выхода **только по RSI**.
- Тренд всё равно **показывается** на UI как справка («сейчас 6H UP/DOWN»).
- В сделки тренд не вмешивается.

### B) `use_trend_as_filter = ON` («опираться на тренд» / фильтр)
- RSI-сигнал обязателен.
- Дополнительно:
  - `ENTER_LONG` разрешён только если тренд ≠ `DOWN` (или строже: только при `UP`, если `require_trend_alignment=true`)
  - `ENTER_SHORT` разрешён только если тренд ≠ `UP` (или только при `DOWN`)
- Если RSI даёт вход, а тренд против — сигнал = `BLOCKED_BY_TREND` (показывать, но не торговать).

Рекомендуемые под-галочки:
- `avoid_down_trend_for_long` (default: true)
- `avoid_up_trend_for_short` (default: true)
- `require_trend_alignment` (default: false) — если true, LONG только при UP, SHORT только при DOWN

### C) `use_trend_only = ON` («только опираться на тренд»)
Взаимоисключает чистый RSI-вход:
- Не открывать по RSI-экстремумам.
- Торговать **по направлению 6H-тренда**:
  - `UP` → только LONG-идеи
  - `DOWN` → только SHORT-идеи
  - `NEUTRAL` → нет входа
- Точка входа в этом режиме (если нужен триггер):
  - либо pullback: RSI возвращается к 40–50 при UP / 50–60 при DOWN;
  - либо простой breakout: новая 6H-свеча с close по стороне тренда.
- Если `use_trend_only=ON`, режимы A/B не применяются к входу.

Приоритет галочек:
1. Если `use_trend_only` → режим C
2. Иначе если `use_trend_as_filter` → режим B
3. Иначе → режим A

При выходе по RSI в режимах B/C сохраняй логику «по тренду / против тренда» из раздела 1.

Для каждого символа из whitelist на каждом обновлении:

```json
  "symbol": "BTCUSDT",
  "strategy": "rsi_6h_mean_reversion",
  "timeframe": "6h",

  "zone": "LOW",
  "signal": "ENTER_LONG",

  "trend_mode": "filter",

  "labels": {
    "chart": "6H LOW · LONG",
    "trend": "6H trend UP"
  },

```

Возможные `signal`:
- `ENTER_LONG`
- `ENTER_SHORT`
- `EXIT_LONG`
- `EXIT_SHORT`
- `WAIT`
- `BLOCKED_BY_TREND`

## 5) UI / ВИЗУАЛИЗАЦИЯ (минимум)

На графике выбранной монеты (любой ТФ):
1. Метка текущего 6H RSI и зоны (LOW/HIGH/NEUTRAL).
2. Метка текущего 6H тренда (UP/DOWN/NEUTRAL).
3. Маркеры исторических сигналов ENTRY на закрытиях 6H.
4. Подсветка, когда «уже LOW» или «уже HIGH» по 6H, даже если пользователь смотрит 5m/15m/1h.
5. Панель настроек стратегии:
   - список монет
   - пороги RSI (с дефолтами выше)
   - галочки тренда (A/B/C)
   - вкл/выкл модуля как отдельной сигнальной системы
