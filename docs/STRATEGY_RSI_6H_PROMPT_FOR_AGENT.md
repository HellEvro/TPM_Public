# Промпт для агента: сигнальная стратегия RSI 6H Mean-Reversion

Скопируй блок ниже целиком и передай другому агенту как ТЗ на внедрение в целевую торговую систему.

---

## ЗАДАЧА

Внедри в существующую торговую систему **отдельный сигнальный модуль / настройку** под названием:

**`RSI 6H Mean-Reversion Signals`**

Модуль:
1. Считает сигналы входа/выхода по фиксированным правилам RSI на `6h`.
2. **Не выдаёт вход сразу** при касании экстремума: ждёт удержания RSI в зоне экстремума N свечей 6h (см. раздел «Удержание на экстремумах»).
3. Показывает на графике (любой ТФ) зоны **LOW / HIGH / ENTRY / WAITING**.
4. Отдельно считает и показывает **6H-тренд** (UP / DOWN / NEUTRAL).
5. Позволяет опционально использовать 6H-тренд в торговых решениях через галочки.
6. Включается как **отдельная надстройка** (сигналы + опционально торговля).

### Символы
- **Нет whitelist.** Модуль работает по **всем символам, которые уже есть в целевой системе**, если настройка модуля включена.
- Не нужно хардкодить BTC/ETH и т.п.
- Не нужны: зрелость монет, сканирование «лишних» пар вне системы, ExitScam, AI-фильтры InfoBot.

### Куда встроить (важно для агента-разработчика)
Агент **сам должен**:
1. Изучить целевую систему (где настройки стратегий, сигнальные пресеты, торговые режимы).
2. Предложить точку интеграции **или спросить у владельца**, куда вешать:
   - тумблер «включить RSI 6H Signals» (панель сигналов / индикаторов);
   - ту же надстройку **в торговле** (выбор стратегии / режим входа / фильтр перед ордером).
3. Не ломать существующие стратегии: модуль — **аддитивная настройка**, которую выбирают явно.

## БАЗОВЫЕ ИНДИКАТОРЫ

Все расчёты сигналов входа/выхода и удержания — на **основном ТФ стратегии = `6h`**.

| Параметр | Значение | Описание |
|----------|----------|----------|
| Timeframe | `6h` | Основной ТФ сигналов |
| RSI period | `14` | Классический RSI по close |
| EMA fast | `50` | Для тренда |
| EMA slow | `200` | Для тренда |
| Trend confirm bars | `3` | Сколько закрытий подряд относительно EMA200 |

На графике пользователь может смотреть **любой ТФ** (1m…1d). Сигналы модуля якорятся к 6H-логике и проецируются на текущий график (маркеры / зоны / метки на соответствующих 6H-свечах).

## 1) RSI-СИГНАЛЫ (ядро)

### Кандидат на вход (ещё НЕ финальный сигнал)

| Условие | Кандидат | Смысл |
|---------|----------|-------|
| `RSI(14, 6h) ≤ 29` | `CANDIDATE_LONG` | зона LOW / перепроданность |
| `RSI(14, 6h) ≥ 71` | `CANDIDATE_SHORT` | зона HIGH / перекупленность |
| `30 ≤ RSI ≤ 70` | `WAIT` | нейтраль, входа нет |

Одного касания экстремума **недостаточно**. Финальный `ENTER_*` только после прохождения **фильтра удержания** (раздел 2).

### Выход (EXIT) по RSI

Учитывается, был ли вход **по тренду** или **против тренда** (см. раздел 4):

| Позиция | Тип входа | Выход |
|---------|-----------|-------|
| LONG | по тренду (entry_trend = UP) | `RSI ≥ 65` |
| LONG | против тренда (entry_trend = DOWN/NEUTRAL) | `RSI ≥ 60` |
| SHORT | по тренду (entry_trend = DOWN) | `RSI ≤ 35` |
| SHORT | против тренда (entry_trend = UP/NEUTRAL) | `RSI ≤ 40` |

Если режим тренда выключен — дефолт выходов: LONG `≥ 65`, SHORT `≤ 35`.

### Зоны для UI (на любом ТФ)

| Зона | Условие (по 6H RSI) | Подпись |
|------|---------------------|---------|
| `LOW` | RSI ≤ 29 | «6H LOW» |
| `HIGH` | RSI ≥ 71 | «6H HIGH» |
| `HOLDING_LOW` | идёт ожидание удержания внизу | «ждём N свечей на лое» |
| `HOLDING_HIGH` | идёт ожидание удержания вверху | «ждём N свечей на хае» |
| `EXIT_LONG_ZONE` | RSI ≥ 60 | «зона выхода лонга» |
| `EXIT_SHORT_ZONE` | RSI ≤ 40 | «зона выхода шорта» |
| `NEUTRAL` | иначе | «ожидание» |

На текущей 6H-свече (и проекции на младший ТФ):
- бейдж `6H LOW` / `6H HIGH` / `6H HOLDING` / `6H WAIT`
- значение RSI 6H
- счётчик: `held X / need N` свечей удержания
- тренд 6H: `UP` / `DOWN` / `NEUTRAL`

## 2) УДЕРЖАНИЕ НА ЭКСТРЕМУМАХ (обязательный фильтр перед входом)

**Смысл:** не входить в первый касание лоя/хая. Сначала RSI должен **подержать экстремум** несколько 6H-свечей (~1–2 дня), не выходя из «спокойной» зоны у края диапазона. Если вышел из зоны раньше — **вход упущен**, сигнал сбрасывается.

### Параметры

| Параметр | Default | Описание |
|----------|---------|----------|
| `hold_candles` (N) | `8` | Целевое ожидание ≈ 2 дня на 6h (`8 × 6h = 48h`) |
| `hold_candles_min` | `4` | Абсолютный минимум (≈ 1 день). N не ниже 4 |
| `hold_zone_upper` | `65` | Верхняя «спокойная» граница для SHORT (не выходить ниже) |
| `hold_zone_lower` | `35` | Нижняя «спокойная» граница для LONG (не выходить выше) |
| `rsi_entry_long` | `29` | Точка экстремума LONG (лой) |
| `rsi_entry_short` | `71` | Точка экстремума SHORT (хай) |

Рекомендация UI: слайдер N от **4 до 8** (или выше), default **8**. Подпись: «ждать ~2 дня (8 свечей 6h) на экстремуме».

### Алгоритм для LONG (`ENTER_LONG`)

1. Смотри последние `N` свечей 6h (история RSI).
2. Найди **самую раннюю (левую)** свечу с `RSI ≤ 29` — это **отправная точка (лой)**.
3. Если лоя в окне нет → `WAITING` / блок: «лой не найден».
4. От этой свечи **до текущей включительно** все RSI должны быть `≤ 35` (держаться внизу, не выходить из нижнего диапазона).
5. Если хоть одна свеча `RSI > 35` → **вход упущен**, `BLOCKED_HOLD_BROKEN` (сброс кандидата).
6. Число свечей от лоя до сейчас (включая обе) должно быть `≥ N` (N ≥ 4).
7. Если меньше N → `WAITING_HOLD`: «ждём удержания, прошло X из N».
8. Если все условия ок → финальный сигнал **`ENTER_LONG`**.

### Алгоритм для SHORT (`ENTER_SHORT`)

Зеркально:
1. В последних N свечах — самая ранняя с `RSI ≥ 71` (хай).
2. От хая до сейчас все RSI `≥ 65` (не проваливаться из верхнего диапазона).
3. Если хоть одна `< 65` → вход упущен.
4. Нужно `≥ N` спокойных свечей (N ≥ 4, default 8).
5. Иначе → `WAITING_HOLD`.
6. Успех → **`ENTER_SHORT`**.

### Важно
- Фильтр удержания — **часть стратегии**, не опциональный «красочный» индикатор. Без него `ENTER_*` **не выдавать**.
- Пока идёт удержание — на UI явно: «уже LOW/HIGH, но вход ещё рано (X/N)».
- Тренд (раздел 3–4) применяется **после** (или вместе с) удержанием: сначала hold, потом trend-mode.

## 3) ТРЕНД 6H (отдельный слой)

Тренд считается **только на 6h**, по EMA:

### UP
Предпочтительно минимум 2 из:
1. `close > EMA200`
2. `EMA50 > EMA200`
3. наклон EMA200 > 0
4. минимум `3` последних close подряд > EMA200

### DOWN
Зеркально относительно EMA200 / EMA50.

### NEUTRAL
Если UP/DOWN не подтверждены.

Флаги:
- `require_price = true`
- `require_candles = true`
- `require_slope = false`
- `min_confirmations = 2`

Тренд всегда **показывается**. На торговлю влияет только через галочки ниже.

## 4) РЕЖИМЫ ТРЕНДА (галочки)

### A) Тренд OFF
- Вход/выход по RSI + удержание.
- Тренд только на UI.

### B) `use_trend_as_filter = ON` («опираться на тренд»)
- Нужны RSI-кандидат + успешное удержание.
- Плюс:
  - LONG не если тренд `DOWN` (`avoid_down_trend_for_long`, default true)
  - SHORT не если тренд `UP` (`avoid_up_trend_for_short`, default true)
- Опционально `require_trend_alignment`: LONG только при `UP`, SHORT только при `DOWN`.
- Иначе → `BLOCKED_BY_TREND`.

### C) `use_trend_only = ON` («только тренд»)
- Не входить по RSI-экстремумам.
- Торговать по направлению 6H-тренда (UP→LONG, DOWN→SHORT, NEUTRAL→нет).
- Триггер входа в этом режиме — на усмотрение реализации (pullback RSI / close по тренду); **удержание на экстремумах к этому режиму не применяется**, либо применяется только если агент явно согласует с владельцем.

Приоритет: C > B > A.

## 5) PAYLOAD СИГНАЛА

Для каждого символа системы (когда модуль включён), на обновлении:

```json
{
  "symbol": "BTCUSDT",
  "strategy": "rsi_6h_mean_reversion",
  "timeframe": "6h",
  "rsi": 27.4,
  "trend": "UP",
  "zone": "HOLDING_LOW",
  "signal": "WAITING_HOLD",
  "signal_reason": "low found; held 5/8 candles <=35",
  "hold": {
    "required": 8,
    "current": 5,
    "extreme_rsi": 24.1,
    "zone_limit": 35,
    "broken": false
  },
  "trend_mode": "off",
  "trade_allowed": false,
  "block_reason": "waiting_hold",
  "levels": {
    "entry_long": 29,
    "entry_short": 71,
    "hold_lower": 35,
    "hold_upper": 65,
    "exit_long": 65,
    "exit_short": 35
  },
  "labels": {
    "chart": "6H LOW · HOLD 5/8",
    "trend": "6H trend UP"
  },
  "updated_at": "ISO-8601"
}
```

Возможные `signal`:
- `WAITING_HOLD` — на экстремуме, ждём N свечей
- `ENTER_LONG` / `ENTER_SHORT` — удержание пройдено (+ тренд-режим ок)
- `EXIT_LONG` / `EXIT_SHORT`
- `WAIT` — вне экстремумов
- `BLOCKED_HOLD_BROKEN` — вышли из зоны удержания раньше срока (вход упущен)
- `BLOCKED_BY_TREND`

`trade_allowed = true` только для реальных `ENTER_*` / `EXIT_*` по правилам модуля.

## 6) UI (минимум)

1. Тумблер модуля (сигналы).
2. Та же надстройка выбирается **в торговле** (агент определяет/спрашивает куда встроить).
3. На графике любого ТФ: 6H RSI, зона LOW/HIGH, счётчик удержания `X/N`, тренд 6H.
4. Маркеры: начало экстремума, спокойные свечи, момент разрешения входа.
5. Настройки: N (4…8+), пороги RSI, галочки тренда A/B/C.

## 7) ЧЕГО НЕ ДЕЛАТЬ

- Не хардкодить список монет — все символы системы при включённой настройке.
- Не выдавать `ENTER_*` без удержания N свечей на экстремуме (кроме согласованного режима C).
- Не внедрять зрелость / ExitScam / AI InfoBot.
- Не подменять 6H-расчёты младшим ТФ.
- Не молча ломать чужие стратегии: точка интеграции — предложить или спросить.
